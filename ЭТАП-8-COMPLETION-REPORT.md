### 5.1 Основные возможности

**Генерация проектов:**
```bash
python3 project_template_generator.py --name my_project --type software
```

**Интерактивный режим:**
```bash
python3 project_template_generator.py --interactive
```

**С расширенными шаблонами:**
```bash
python3 project_template_generator.py --name my_app --type software --templates
```

**С Git инициализацией:**
```bash
python3 project_template_generator.py --name my_app --type software --init-git
```

**С GitHub репозиторием:**
```bash
python3 project_template_generator.py --name my_app --type software --create-github-repo
```

**С CI/CD:**
```bash
python3 project_template_generator.py --name my_app --type software --setup-ci
```

**Все функции сразу:**
```bash
python3 project_template_generator.py --name my_app --type software --templates --init-git --create-github-repo --setup-ci --setup-security --setup-quality --setup-deploy
```

## 6. ИНТЕГРАЦИЯ С МЕТОДОЛОГИЕЙ ⇑⇓↔

### 6.1 α-уровни в шаблонах

Каждый шаблон маркирован α-уровнем:

- **α=+4 (Онтология):** Фундаментальные принципы
- **α=+3 (Философия):** Ценности и миссия
- **α=+2 (Стратегия):** Долгосрочное планирование
- **α=+1 (Принципы):** Архитектурные решения
- **α=0 (Применение):** Конкретные методы
- **α=-1 (Инструменты):** Практические инструменты
- **α=-2 (Операции):** Ежедневная работа
- **α=-3 (Детали):** Специфические детали
- **α=-4 (Код):** Исполняемый код

**Примеры:**
- BUSINESS-PLAN-TEMPLATE.md: α=+2 (стратегия)
- ARCHITECTURE-TEMPLATE.md: α=+1 (принципы)
- PRODUCTION-PLAN-TEMPLATE.md: α=-1 (операции)
- CROP-PLAN-TEMPLATE.md: α=-2 (операции)

### 6.2 Направления ⇑⇓↔

**⇑ ВВЕРХ (от деталей к абстракции):**
- От кода к архитектуре
- От операций к стратегии
- Обобщение и рефлексия

**⇓ ВНИЗ (от абстракции к деталям):**
- От стратегии к реализации
- От принципов к практике
- Конкретизация

**↔ ГОРИЗОНТ (на том же уровне):**
- Связь с другими проектами
- Интеграция со стандартами
