## Введение

Этот документ визуализирует **полную вертикальную трассируемость** проекта info1 — от абстрактных философских оснований до конкретного исполняемого кода.

**Цель:** Показать, что каждая строка кода имеет чёткую связь с философией проекта, и наоборот — каждый философский принцип реализован в коде.

**Философия:** Проект без вертикальной трассируемости — это здание без фундамента. Код без философии — бессмысленный набор инструкций.

### Уровень α=-4: КОД

**Файл:** [08-Программная-реализация/card_system/models.py](08-Программная-реализация/card_system/models.py)

**Исполняемая реализация:**

```python
class MedicineCard(BaseCard):
    """
    Карточка лекарства.

    Реализует принцип "Достоинство":
    - Простой интерфейс без технического жаргона
    - Понятные названия полей (не "drug" а "лекарство")
    - Дружелюбные напоминания, а не строгие предупреждения

    Уровень абстракции: α=-4
    Философия: Уважение к пользователю (α=+3)
    """

    def __init__(self, name, dosage, frequency, time, notes=''):
        super().__init__(type='medicine')
        self.name = name           # Название лекарства
        self.dosage = dosage       # Дозировка (например, "100 мг")
        self.frequency = frequency # Частота (например, "1 раз в день")
        self.time = time           # Время приёма (например, "09:00")
        self.notes = notes         # Дополнительные заметки

    def get_reminder_text(self):
        """
        Генерирует дружелюбное напоминание.

        Реализует принцип "Простота" (α=+3):
        - Человеческий язык, а не технический
        - Позитивный тон, а не строгий
        """
        return f"Пора принять {self.name} ({self.dosage})"

    def validate(self):
        """
        Проверяет корректность данных.

        Реализует принцип "Эмпатия" (α=+3):
        - Понятные сообщения об ошибках
        - Подсказки, как исправить
        """
        if not self.name:
            raise ValueError(
                "Пожалуйста, укажите название лекарства. "
                "Например: 'Аспирин' или 'Витамин D'"
            )

        if not self.dosage:
            raise ValueError(
                "Пожалуйста, укажите дозировку. "
                "Например: '100 мг' или '1 таблетка'"
            )

        return True
```
