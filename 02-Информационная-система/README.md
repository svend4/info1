# Информационная операционная система для домашнего использования

## Концепция

Информационная система основана на проверенных временем методах организации информации (картотеки, записные книжки, досье) с адаптацией под современные цифровые технологии и потребности пожилых людей.

## Фундаментальные принципы

### 1. Атомарность информации

Вся информация разбивается на **карточки** - минимальные самодостаточные единицы информации. Каждая карточка содержит одну законченную мысль, задачу, рецепт, контакт и т.д.

**Преимущества:**
- Легко создавать
- Легко находить
- Легко обновлять
- Легко комбинировать
- Легко удалять без потери связанной информации

### 2. Иерархическая организация

```
Карточка (атом)
    ↓
Записная книжка (коллекция карточек)
    ↓
Проект (группа карточек с целью)
    ↓
Цикл (повторяющиеся проекты)
    ↓
Жизнь (совокупность циклов)
```

### 3. Гибкость группировки

Одна карточка может одновременно принадлежать:
- Нескольким записным книжкам
- Нескольким проектам
- Нескольким циклам

Это достигается через систему **тегов** и **связей**.

## Базовые элементы системы

### Карточка (Card)

Минимальная единица информации.

**Структура карточки:**
```
┌─────────────────────────────────────┐
│ [Тип] Заголовок                     │
├─────────────────────────────────────┤
│ Содержание:                         │
│ Основной текст, описание            │
│                                     │
├─────────────────────────────────────┤
│ Теги: #дом #кухня #готовка          │
│ Связи: → карточка-123, → карточка-456│
│ Цикл: Дневной                       │
│ Приоритет: Средний                  │
│ Дата создания: 2026-01-23           │
│ Последнее обновление: 2026-01-23    │
└─────────────────────────────────────┘
```

**Типы карточек:**

1. **Задача** - действие, которое нужно выполнить
   - Статус: не начата / в процессе / выполнена / отложена
   - Срок выполнения
   - Повторяемость
   - Исполнитель (человек/робот/устройство)

2. **Информация** - справочные данные
   - Факты
   - Инструкции
   - Контакты
   - Важные данные

3. **Рецепт** - пошаговое руководство
   - Ингредиенты/компоненты
   - Последовательность действий
   - Время выполнения
   - Необходимые инструменты

4. **Покупка** - товар для приобретения
   - Наименование
   - Количество
   - Магазин/категория
   - Приоритет

5. **Заметка** - быстрая запись
   - Мысли
   - Идеи
   - Напоминания

6. **Медицинская** - данные о здоровье
   - Лекарства
   - Процедуры
   - Симптомы
   - Визиты к врачу

### Записная книжка (Notebook)

Коллекция связанных карточек по определенной теме.

**Примеры записных книжек:**
- "Рецепты"
- "Контакты"
- "Медицинская информация"
- "Уход за домом"
- "Финансы"
- "Хобби и увлечения"
- "Ремонт и обслуживание"

**Структура записной книжки:**
```
Записная книжка: "Рецепты"
├── Первые блюда
│   ├── Карточка: Борщ
│   ├── Карточка: Щи
│   └── Карточка: Суп-лапша
├── Вторые блюда
│   ├── Карточка: Котлеты
│   └── Карточка: Плов
└── Десерты
    ├── Карточка: Шарлотка
    └── Карточка: Печенье
```

### Проект (Project)

Группа карточек, объединенных общей целью.

**Отличие от записной книжки:**
- Записная книжка - статическая коллекция для хранения
- Проект - активная работа с началом и концом

**Примеры проектов:**
- "Подготовка к дню рождения"
- "Весенняя уборка дома"
- "Ремонт в ванной"
- "Посадка огорода"
- "Недельное меню"

**Структура проекта:**
```
Проект: "Подготовка к дню рождения"
├── Планирование
│   ├── Карточка: Составить список гостей
│   ├── Карточка: Выбрать дату
│   └── Карточка: Определить бюджет
├── Покупки
│   ├── Карточка: Продукты для меню
│   ├── Карточка: Украшения
│   └── Карточка: Подарки
├── Подготовка
│   ├── Карточка: Уборка квартиры
│   ├── Карточка: Приготовление блюд
│   └── Карточка: Сервировка стола
└── Проведение
    ├── Карточка: Встреча гостей
    └── Карточка: Развлекательная программа
```

**Статусы проекта:**
- Планируется
- Активный
- Приостановлен
- Завершен
- Отменен

### Цикл (Cycle)

Повторяющаяся последовательность задач.

**Типы циклов:**

1. **Дневной цикл**
   - Утренние процедуры
   - Прием лекарств
   - Приготовление пищи
   - Уборка
   - Вечерние процедуры

2. **Недельный цикл**
   - Генеральная уборка (суббота)
   - Покупки продуктов (пятница)
   - Стирка (среда, воскресенье)
   - Оплата счетов
   - Посещение врача

3. **Месячный цикл**
   - Проверка бытовой техники
   - Генеральная уборка всего дома
   - Проверка запасов
   - Планирование на следующий месяц

4. **Годовой цикл**
   - Сезонные работы (весна: огород, лето: консервация, осень: подготовка к зиме)
   - Медицинские осмотры
   - Замена фильтров
   - Профилактика техники

## Система тегов и категорий

### Теги

Гибкая система меток для быстрого поиска и группировки.

**Категории тегов:**

**1. Локация:**
- #кухня, #спальня, #ванная, #гостиная, #кладовка
- #сад, #гараж, #двор, #крыша
- #магазин, #аптека, #поликлиника

**2. Активность:**
- #готовка, #уборка, #стирка, #ремонт
- #здоровье, #досуг, #общение
- #финансы, #покупки

**3. Время:**
- #утро, #день, #вечер, #ночь
- #будни, #выходные
- #весна, #лето, #осень, #зима

**4. Приоритет:**
- #срочно, #важно, #можно-отложить
- #критично, #желательно, #опционально

**5. Исполнитель:**
- #человек, #робот, #автоматика
- #требует-помощи, #самостоятельно
- #робот-уборщик, #робот-садовник

**6. Состояние:**
- #активно, #завершено, #отложено, #отменено
- #требует-внимания, #в-процессе

### Связи между карточками

**Типы связей:**

1. **Последовательная** (→)
   - Карточка А должна быть выполнена перед Карточкой Б
   - Пример: "Купить продукты" → "Приготовить обед"

2. **Ссылочная** (↔)
   - Карточки связаны тематически
   - Пример: "Рецепт борща" ↔ "Список продуктов для борща"

3. **Родительская** (↑)
   - Карточка является частью другой карточки
   - Пример: "Уборка кухни" ↑ "Генеральная уборка"

4. **Дублирующая** (≈)
   - Карточки описывают одно и то же
   - Для объединения или выбора лучшего варианта

## Интеграция с робототехникой

### Карточки-задания для роботов

Каждая задача в карточке может иметь поле "Исполнитель":
- Человек
- Робот (с указанием типа)
- Умное устройство
- Совместно

**Пример:**
```
┌──────────────────────────────────┐
│ [Задача] Уборка гостиной         │
│ Исполнитель: Робот-уборщик #5    │
│ Время: Ежедневно, 10:00          │
│ Область: Гостиная, 25 м²         │
│ Действия:                        │
│ - Пропылесосить пол              │
│ - Протереть пыль (если есть функция)│
│ - Вернуться на базу              │
│ Условия запуска:                 │
│ - Нет людей в комнате            │
│ - Достаточно заряда (>30%)       │
│ После завершения:                │
│ - Отметить задачу как выполненную│
│ - Уведомить о завершении         │
│ - Если ошибка: уведомить владельца│
└──────────────────────────────────┘
```

### Координация через робота-координатора

Робот-координатор читает карточки-задания и распределяет их между мини-роботами:

```
Робот-координатор видит проект: "Утренняя уборка"

Анализирует карточки:
├── Задача 1: Пропылесосить → Назначает: Робот-пылесос А
├── Задача 2: Полить цветы → Назначает: Робот-садовник Б
├── Задача 3: Вынести мусор → Назначает: Робот-курьер В
└── Задача 4: Протереть окна → Назначает: Робот-мойщик Г

Роботы работают параллельно.
Координатор отслеживает прогресс.
По завершении обновляет статусы карточек.
```

## Интерфейсы взаимодействия

### Для пожилых людей

**1. Голосовой интерфейс**
- "Добавь в список покупок молоко"
- "Покажи мои задачи на сегодня"
- "Когда мне принимать лекарства?"
- "Напомни мне позвонить доктору завтра в 10 утра"

**2. Упрощенный визуальный интерфейс**
- Крупные шрифты
- Контрастные цвета
- Минимум кнопок
- Простая навигация
- Иконки с подписями

**3. Физические карточки (опционально)**
- Распечатанные карточки для тех, кто предпочитает бумагу
- Синхронизация через фото/сканирование
- Гибридная система (бумага + цифра)

**4. Настенные дисплеи/планшеты**
- В каждой комнате
- Показывают актуальные задачи для этой комнаты
- Напоминания
- Текущее время, погода

### Для родственников (удаленный доступ)

- Мобильное приложение
- Уведомления о важных событиях
- Возможность добавлять напоминания удаленно
- Мониторинг здоровья (с разрешения)
- Видеосвязь

## Автоматизация и умные функции

### Автоматическое создание карточек

**На основе паттернов:**
- Система замечает, что каждую пятницу создается карточка "Покупки"
- Предлагает создать повторяющуюся карточку
- Автоматически создает её каждую неделю

**На основе событий:**
- Заканчиваются лекарства → создается карточка "Купить [название]"
- Приближается день рождения → создается проект "Подготовка"
- Сезонное изменение → активируются сезонные карточки

### Умные напоминания

- Учитывают расписание и привычки
- Адаптируются под обратную связь
- Приоритизируют важные напоминания
- Группируют связанные напоминания

### Аналитика и отчеты

- Сколько задач выполнено за день/неделю/месяц
- Какие задачи часто откладываются
- Оптимизация расписания
- Рекомендации по улучшению

## Хранение данных

### Принципы

1. **Локальное хранение**
   - Основные данные хранятся локально (дома)
   - Полный контроль над информацией
   - Работает без интернета

2. **Резервное копирование**
   - Автоматическое резервное копирование
   - Несколько копий (локальная + облако + физическая)
   - Шифрование чувствительных данных

3. **Синхронизация**
   - Между устройствами в доме
   - С мобильными устройствами
   - С устройствами родственников (с разрешениями)

### Формат данных

**Текстовый формат** (Markdown + YAML):
- Легко читается человеком
- Легко редактируется
- Не зависит от специального ПО
- Долговечность данных

**Пример файла карточки:**
```markdown
---
id: card-20260123-001
type: задача
title: Полить цветы
status: активна
cycle: дневной
time: 18:00
executor: человек/робот-садовник

## Миграция для пожилых людей

### Этап 1: Знакомство
- Демонстрация на простых примерах
- Использование привычных аналогий (бумажные записки, календарь)
- Без давления, в комфортном темпе

### Этап 2: Первые карточки
- Начать с 3-5 простых карточек
- Список покупок - понятный всем пример
- Напоминания о лекарствах

### Этап 3: Расширение
- Постепенное добавление функций

### Для пожилых людей

   - Лекарства
   - Встречи с врачами
   - Звонки родственникам

2. **Структурированность жизни**
   - Понятный распорядок дня
   - Повторяющиеся циклы
   - Предсказуемость

3. **Снижение когнитивной нагрузки**
   - Не нужно все держать в голове
   - Система напомнит
   - Меньше стресса

4. **Независимость**
   - Меньше зависимости от помощи других
   - Контроль над своей жизнью
   - Уверенность в себе

### Для родственников

1. **Спокойствие**
   - Знают, что близкий не забудет важное
   - Мониторинг (с разрешения)
   - Быстрая связь при необходимости

2. **Эффективная помощь**
   - Видят, в чем нужна помощь
   - Могут добавлять напоминания удаленно
   - Координация ухода
