# Шаблоны карточек [α=-2]

## Введение

Этот документ содержит готовые шаблоны для создания карточек разных типов. Уровень абстракции α=-2 — конкретные шаблоны на основе технических спецификаций (α=-1).

Каждый шаблон можно скопировать и заполнить своими данными.

---

# Полить цветы на подоконнике

## Описание

Еженедельный полив комнатных растений на подоконнике в спальне.

## Шаги выполнения

1. Взять лейку с водой комнатной температуры
2. Проверить влажность почвы пальцем в каждом горшке

- Лейка
- Вода комнатной температуры
- Влажная тряпка

Не переливать! Лучше недолить, чем перелить.

# Эналаприл 10мг

## Показания

Назначен для контроля артериального давления при гипертонии.

## Инструкция по применению

1. Принимать ежедневно в 19:00
2. Не разжёвывать таблетку
3. Запить полным стаканом воды (200мл)
4. Можно принимать независимо от приёма пищи
5. Измерить давление через 2 часа после приёма

## Важно помнить

- Нельзя резко прекращать приём (снижать дозу постепенно)
- При головокружении медленно вставать с кровати
- Не употреблять грейпфрутовый сок
- Избегать алкоголя
- Контролировать давление ежедневно

## Что делать при пропуске

Если пропустили приём:
- Менее 12 часов: принять как вспомнили
- Более 12 часов: пропустить, принять следующую дозу по расписанию
- НЕ принимать двойную дозу!

# Борщ классический

## Ингредиенты (на 6 порций)

**Для бульона:**
- Говядина на кости — 500г
- Вода — 3 литра
- Соль — по вкусу

**Для борща:**
- Свёкла — 2 средних
- Капуста белокочанная — 300г
- Картофель — 3 средних
- Морковь — 1 крупная
- Лук репчатый — 1 крупный
- Томатная паста — 2 ст.л.
- Растительное масло — 3 ст.л.
- Чеснок — 3 зубчика
- Соль, перец, лавровый лист — по вкусу

## Приготовление

### 1. Бульон (40 минут)

1. Мясо промыть, залить холодной водой (3 литра)
2. Довести до кипения, снять пену
3. Варить на медленном огне 1,5 часа
4. Мясо достать, остудить, нарезать кусочками
5. Бульон процедить

### 2. Овощная заправка (30 минут)

1. Свёклу натереть на крупной тёрке
2. Морковь натереть на средней тёрке
3. Лук нарезать мелким кубиком
4. Капусту нашинковать

### 3. Приготовление борща (40 минут)

1. В бульон положить нарезанный картофель
2. Варить 10 минут
3. На сковороде обжарить лук до прозрачности (5 мин)
4. Добавить морковь, жарить 5 минут
5. Добавить свёклу, томатную пасту, 1 стакан бульона
6. Тушить 10 минут
7. В кастрюлю добавить капусту, варить 10 минут
8. Добавить овощную заправку
9. Добавить мясо
10. Варить 10 минут
11. Добавить лавровый лист, соль, перец
12. Добавить давленый чеснок
13. Выключить огонь, дать настояться 15 минут

## Подача

Подавать горячим со сметаной, свежим хлебом или пампушками с чесноком.

## Советы

- Для яркого цвета добавьте в свёклу при тушении 1 ч.л. уксуса или лимонного сока
- Можно добавить фасоль для сытности
- Борщ вкуснее на второй день
- Можно заморозить порциями
- Традиционно подаётся с салом и чесноком

# Идея: автоматический полив в теплице

## Проблема

Каждый день нужно вручную поливать растения в теплице. Летом в жару приходится поливать 2 раза в день. Это отнимает ~30 минут ежедневно.

## Идея решения

Установить систему автоматического полива с датчиками влажности почвы:

1. **Датчики влажности** в каждой грядке
2. **Капельная система полива** с таймером
3. **Контроллер** (можно Arduino или Raspberry Pi)
4. **Интеграция с общей системой роботов**

## Как это будет работать

1. Датчики измеряют влажность почвы каждый час
2. Когда влажность падает ниже порога (например, 30%)
3. Контроллер включает насос
4. Вода подаётся через капельную систему
5. Когда влажность достигает 60% — насос выключается
6. Робот-координатор получает уведомление о поливе

## Необходимые компоненты

- Датчики влажности почвы — 6 шт (~300₽/шт = 1800₽)
- Капельная лента — 50м (~500₽)
- Насос для полива — 1 шт (~3000₽)
- Arduino/контроллер — 1 шт (~1500₽)
- Бак для воды — есть
- Провода, фитинги — ~1000₽

**Итого:** ~7800₽

## Преимущества

- Экономия времени: 30 мин × 365 дней = 182 часа в год!
- Оптимальный полив (не перелив, не недолив)
- Можно уезжать на несколько дней
- Снижение расхода воды на 30-40%

## Следующие шаги

1. Изучить подробнее систему капельного полива
2. Выбрать конкретные модели датчиков и контроллера
3. Нарисовать схему подключения
4. Посчитать точную стоимость

6. Установить систему весной (март-апрель)

- Использовать данные о погоде для корректировки полива

## Использование шаблонов

### Как создать карточку из шаблона

1. **Скопировать нужный шаблон**
2. **Сгенерировать ID** (или использовать функцию автогенерации)
3. **Заполнить обязательные поля**
4. **Заполнить содержимое**
5. **Сохранить в соответствующую папку**

### Автоматизация создания

Можно создать скрипты для быстрого создания карточек:

```bash
#!/bin/bash
# create_card.sh

TYPE=$1  # task, medicine, recipe, и т.д.
TITLE=$2

# Генерация ID
ID=$(date +card_%Y%m%d_%H%M%S)_$(openssl rand -hex 2)

# Копирование шаблона
cp templates/${TYPE}_template.card.md cards/${TYPE}/${ID}.card.md

# Замена placeholder'ов
sed -i "s/card_YYYYMMDD_HHMMSS_xxxx/${ID}/g" cards/${TYPE}/${ID}.card.md
sed -i "s/\[Название задачи\]/${TITLE}/g" cards/${TYPE}/${ID}.card.md

# Открыть в редакторе
nano cards/${TYPE}/${ID}.card.md
```

---

**Статус:** Готово к использованию
**Уровень абстракции:** α = -2 (готовые шаблоны)
**Связи:**
- Вверх: ТЕХНИЧЕСКИЕ-СПЕЦИФИКАЦИИ.md (α=-1)
- Вниз: Примеры/ (α=-3, готовые заполненные карточки)
