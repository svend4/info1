## Введение

Карточная система — это простой и гибкий инструмент для организации домашней информации. Вся ваша информация хранится в виде **карточек** — небольших текстовых файлов в формате Markdown с метаданными.

### Почему карточки?

✅ **Просто:** Один файл = одна карточка
✅ **Гибко:** 7 типов карточек для разных нужд
✅ **Надёжно:** Файлы на диске, работает без интернета
✅ **Универсально:** Markdown читают все редакторы
✅ **Мощно:** Поиск, связи, экспорт, статистика

## Быстрый старт (5 минут)

### Шаг 1: Установка

Скопируйте директорию `card_system/` к себе на компьютер:

```bash
cp -r 08-Программная-реализация/card_system ~/my_cards_system
cd ~/my_cards_system
```

### Шаг 2: Создайте первую карточку

```bash
python cli.py create -t task --title "Купить молоко"
```

**Результат:**
```
✅ Создана карточка: card_20260123_100000_a1b2
```

### Шаг 3: Посмотрите карточку

```bash
python cli.py show card_20260123_100000_a1b2
```

**Вы увидите:**
```
📝 Задача: Купить молоко

ID: card_20260123_100000_a1b2
Тип: task
Статус: pending
Приоритет: medium
Создана: 2026-01-23 10:00:00

Теги: нет
Связи: нет
```

### Шаг 4: Найдите карточку

```bash
python cli.py search --query "молоко"
```

**Готово!** Вы создали, просмотрели и нашли карточку.

## 7 типов карточек

Система поддерживает 7 типов карточек для разных сценариев:

### 1. 📋 Задача (task)

**Для чего:** Дела, которые нужно сделать

**Создание:**
```bash
python cli.py create -t task \
    --title "Позвонить врачу" \
    --priority high \
    --due "2026-01-25" \
    --tags здоровье,срочно
```

**Пример карточки:**
```markdown
---
id: card_20260123_100000_a1b2
type: task
title: "Позвонить врачу"
status: pending
priority: high
due_date: 2026-01-25T00:00:00
tags: [здоровье, срочно]
---

# Позвонить врачу

Записаться на приём к терапевту. Телефон: +7-123-456-78-90.
```

### 2. 💊 Лекарство (medicine)

**Для чего:** Отслеживание приёма лекарств

**Создание:**
```bash
python cli.py create -t medicine \
    --title "Эналаприл 10мг" \
    --tags здоровье,гипертония
```

**Пример использования:**
- Напоминания о приёме
- Отслеживание остатка
- История приёма

### 3. 📖 Рецепт (recipe)

**Для чего:** Кулинарные рецепты

**Создание:**
```bash
python cli.py create -t recipe \
    --title "Овсяная каша" \
    --tags завтрак,здоровое-питание
```

**Пример карточки:**
```markdown
---
id: card_20260123_100000_c3d4
type: recipe
title: "Овсяная каша"
servings: 2
prep_time: 5
cook_time: 10
tags: [завтрак, здоровое-питание]
---

# Овсяная каша

## Ингредиенты
- Овсяные хлопья — 100г
- Вода — 400мл
- Соль — щепотка

## Приготовление
1. Вскипятить воду
2. Добавить хлопья
3. Варить 5-7 минут
```

### 4. 🛒 Покупки (shopping)

**Для чего:** Списки покупок

**Создание:**
```bash
python cli.py create -t shopping \
    --title "Продукты на неделю" \
    --tags покупки
```

**Пример:**
- ☐ Молоко 1л
- ☐ Хлеб 2шт
- ☑ Яйца 10шт (куплено!)

### 5. 👤 Контакт (contact)

**Для чего:** Важные контакты

**Создание:**
```bash
python cli.py create -t contact \
    --title "Врач Иванов" \
    --tags здоровье,врачи
```

**Содержит:**
- Имя, телефон, email
- Адрес
- Заметки

### 6. 📅 Встреча (appointment)

**Для чего:** Встречи, приёмы, события

**Создание:**
```bash
python cli.py create -t appointment \
    --title "Приём у стоматолога" \
    --tags здоровье,врачи
```

**Содержит:**
- Дата и время
- Место
- Участники

### 7. 📝 Заметка (note)

**Для чего:** Любая информация

**Создание:**
```bash
python cli.py create -t note \
    --title "Идея для проекта" \
    --tags идеи
```

**Универсальный тип** для всего, что не подходит под другие категории.

## Практические сценарии

### Сценарий 1: Утренний распорядок

**Цель:** Организовать утренние дела

```bash
# 1. Создать задачу "Утренняя зарядка"
python cli.py create -t task \
    --title "Утренняя зарядка" \
    --tags здоровье,утро \
    --priority medium

# 2. Создать карточку лекарства
python cli.py create -t medicine \
    --title "Эналаприл 10мг" \
    --tags здоровье,утро

# 3. Создать задачу "Принять лекарство"
python cli.py create -t task \
    --title "Принять утреннее лекарство" \
    --tags здоровье,утро \
    --priority high \
    --due "2026-01-24 08:00"

# 4. Найти все утренние дела
python cli.py search --tags утро
```

**Результат:** Все утренние дела собраны в одном месте, легко найти через тег "утро".

### Сценарий 2: Планирование покупок

**Цель:** Не забыть купить нужное

```bash
# 1. Создать список покупок
python cli.py create -t shopping \
    --title "Покупки на выходные" \
    --tags покупки

# 2. Добавить рецепт, для которого нужны продукты
python cli.py create -t recipe \
    --title "Борщ" \
    --tags обед,суп

# 3. Создать задачу "Купить продукты"
python cli.py create -t task \
    --title "Купить продукты для борща" \
    --tags покупки \
    --due "2026-01-25"

# 4. Связать задачу с рецептом и списком
python cli.py link <task_id> <recipe_id>
python cli.py link <task_id> <shopping_id>
```

**Результат:** Задача связана с рецептом, видно, для чего нужны покупки.

### Сценарий 3: Медицинские записи

**Цель:** Отследить приём лекарств и визиты к врачу

```bash
# 1. Создать карточку врача
python cli.py create -t contact \
    --title "Терапевт Петров И.И." \
    --tags здоровье,врачи

# 2. Создать встречу с врачом
python cli.py create -t appointment \
    --title "Приём у терапевта" \
    --tags здоровье \
    --due "2026-01-30 10:00"

# 3. Создать карточки лекарств
python cli.py create -t medicine \
    --title "Эналаприл 10мг" \
    --tags здоровье,гипертония

# 4. Создать задачу приёма лекарства
python cli.py create -t task \
    --title "Принять эналаприл" \
    --tags здоровье \
    --priority high

# 5. Связать всё вместе
python cli.py link <appointment_id> <contact_id>
python cli.py link <task_id> <medicine_id>
```

**Результат:** Полная картина: когда приём, у какого врача, какие лекарства принимать.

## Поиск карточек

### Простой поиск по тексту

```bash
python cli.py search --query "молоко"
```

Найдёт все карточки, где в заголовке или содержимом есть слово "молоко".

### Поиск по тегам

```bash
python cli.py search --tags здоровье
```

Найдёт все карточки с тегом "здоровье".

### Поиск по нескольким тегам (И)

```bash
python cli.py search --tags здоровье,срочно
```

Найдёт карточки, у которых есть **оба** тега.

### Поиск по типу

```bash
python cli.py list --type task
```

Покажет только задачи.

### Поиск по статусу

```bash
python cli.py list --status pending
```

Покажет только карточки со статусом "pending".

### Комбинированный поиск

```bash
python cli.py search \
    --query "лекарство" \
    --tags здоровье \
    --type task \
    --status pending
```

Найдёт **незавершённые задачи** с тегом "здоровье", где упоминается "лекарство".

## Связывание карточек

Карточки можно связывать друг с другом, создавая **граф знаний**.

### Зачем связывать?

- 📋 Задача → 💊 Лекарство: "Принять лекарство X"
- 📖 Рецепт → 🛒 Покупки: "Купить продукты для рецепта"
- 📅 Встреча → 👤 Контакт: "Встреча с доктором Ивановым"

### Как связать

```bash
# Связать задачу с лекарством
python cli.py link <task_id> <medicine_id>

# Пример
python cli.py link card_20260123_100000_a1b2 card_20260123_100030_c3d4
```

**Результат:**
```
✅ Связаны: card_20260123_100000_a1b2 ↔ card_20260123_100030_c3d4
```

### Посмотреть связанные карточки

```bash
python cli.py show <card_id>
```

Покажет карточку и все связанные с ней.

## Обновление и удаление

### Обновить карточку

```bash
python cli.py update <card_id> \
    --title "Новое название" \
    --status completed \
    --priority low
```

### Завершить задачу

```bash
python cli.py update <task_id> --status completed
```

### Удалить карточку (soft delete)

```bash
python cli.py delete <card_id>
```

**Важно:** Карточка НЕ удаляется физически, а архивируется (status = archived). Можно восстановить!

**Результат:** Файл `backup.json` со всеми карточками.


**Результат:** ZIP-архив со всеми карточками в Markdown.

### Импорт из JSON

```bash
python export_import.py import-json backup.json --cards-dir ./cards
```

**Результат:** Все карточки восстановлены из backup.

### Импорт из директории

```bash
python export_import.py import-dir ./old_cards --cards-dir ./cards
```

Импортирует все `.md` файлы из директории `old_cards`.

## FAQ

### Где хранятся карточки?

В директории `./cards/` (по умолчанию). Каждая карточка — это файл `.md`.

### Можно ли редактировать карточки вручную?

**Да!** Файлы в формате Markdown с YAML frontmatter. Откройте любым текстовым редактором.

### Как сделать backup?

```bash
python export_import.py export-zip backup.zip --cards-dir ./cards
```

### Как перенести на другой компьютер?

1. Экспортируйте в ZIP
2. Скопируйте ZIP на другой компьютер
3. Импортируйте из ZIP

### Работает ли без интернета?

**Да!** Всё работает локально, интернет не нужен.

### Можно ли использовать с Git?

**Да!** Карточки — это текстовые файлы, отлично работают с Git:

```bash
cd cards/
git init
git add .
git commit -m "Initial commit"
```

### Сколько карточек может быть?

**Тысячи.** Система протестирована на 500 карточках, поиск за < 0.1 секунды.

### Как искать по дате создания?

```bash
python cli.py list | grep "2026-01-23"
```

### Можно ли прикреплять файлы?

Карточка — это Markdown файл. Можно добавить ссылки на файлы:

```markdown
# Рецепт борща

![Фото](./photos/borsch.jpg)

[PDF рецепт](./recipes/borsch.pdf)
```

### Есть ли веб-интерфейс?

Пока нет, только CLI. Но можно открывать `.md` файлы в любом Markdown-редакторе (Obsidian, Typora, VSCode).

## Советы и лучшие практики

### 1. Используйте теги щедро

Теги — это основной способ организации. Добавляйте несколько тегов:

```
--tags здоровье,врачи,срочно
```

### 2. Связывайте связанное

Если задача относится к лекарству, **свяжите** их. Граф связей помогает видеть контекст.

### 3. Регулярный backup

Раз в неделю делайте backup:

```bash
python export_import.py export-zip backup_$(date +%Y%m%d).zip
```

### 4. Используйте статусы

Обновляйте статус задач:
- `pending` → `in_progress` → `completed` → `archived`

### 5. Приоритеты важны

Ставьте приоритеты:
- `high` — срочное
- `medium` — обычное
- `low` — можно отложить

### 6. Даты выполнения

Для задач указывайте `--due`, чтобы не забыть:

```bash
--due "2026-01-25"
```

### 7. Содержимое карточки

После создания откройте файл карточки и добавьте детали:

```bash
# Найти файл
ls cards/*.md | grep <card_id>

# Открыть в редакторе
nano cards/card_20260123_100000_a1b2.md
```
