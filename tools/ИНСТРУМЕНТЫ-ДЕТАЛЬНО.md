## 1. health_metrics.py — Расчёт метрик здоровья

**Уровень абстракции:** α=-4 (исполняемый код)  
**Назначение:** Автоматический расчёт 4 метрик здоровья проекта

### Реализует концепции

⇑ **Связь к теории:**
- [../МЕТРИКИ-ЗДОРОВЬЯ.md](../МЕТРИКИ-ЗДОРОВЬЯ.md) (α=+2) — определения метрик CD, VT, CR, DB
- [../ЭТАП-6-САМОСОВЕРШЕНСТВОВАНИЕ.md](../ЭТАП-6-САМОСОВЕРШЕНСТВОВАНИЕ.md) (α=+2) — концепция автоматического измерения
- [../ЭВОЛЮЦИЯ-МЕТОДОЛОГИИ.md](../ЭВОЛЮЦИЯ-МЕТОДОЛОГИИ.md) (α=+2) — ЭТАП 5 (автоматизация)

### Вычисляемые метрики

1. **CD (Connectivity Density)** — плотность связей
   - Формула: `(actual_connections / max_possible) × 100%`
   - Целевой диапазон: 16.5-33%
   - Измеряет: насколько документы связаны друг с другом

2. **VT (Vertical Traceability)** — вертикальная трассируемость
   - Формула: `(vertical_connections / total_connections) × 100%`
   - Целевой диапазон: 22-44%
   - Измеряет: долю связей между разными уровнями абстракции

3. **CR (Convergence Rate)** — скорость сходимости
   - Формула: среднее отношение роста документов по циклам
   - Целевой диапазон: 0.6-1.3
   - Измеряет: скорость развития проекта

4. **DB (Directional Balance)** — баланс направлений
   - Формула: `(std_dev(⇑,⇓,↔) / mean(⇑,⇓,↔)) × 100%`
   - Целевой диапазон: <132%
   - Измеряет: сбалансированность направлений развития

### Ключевые функции

- `_scan_documents()` — сканирование всех .md файлов
- `_extract_alpha()` — извлечение уровня абстракции α
- `_extract_direction()` — извлечение направления ⇑⇓↔ (исправлено в v0.9)
- `_extract_connections()` — извлечение связей между документами
- `calculate_vt()`, `calculate_db()`, etc. — расчёт метрик

### Использование

```bash
python3 tools/health_metrics.py
```

⇓ **Реализация:** [health_metrics.py](health_metrics.py)

## 2. self_improvement.py — Автоматические рекомендации

**Уровень абстракции:** α=-4 (исполняемый код)  
**Назначение:** Диагностика проблем и генерация рекомендаций по улучшению

⇑ **Связь к теории:**
- [../ЭТАП-6-САМОСОВЕРШЕНСТВОВАНИЕ.md](../ЭТАП-6-САМОСОВЕРШЕНСТВОВАНИЕ.md) (α=+2) — концепция самодиагностики

## 3. enrich_alpha.py — Автоматическое обогащение α-уровнями

**Уровень абстракции:** α=-4 (исполняемый код)  
**Назначение:** Автоматическое добавление метаданных α-уровня к документам

### Реализует концепции

⇑ **Связь к теории:**
- [../ЭТАП-7-КОЛЛЕКТИВНЫЙ-ИНТЕЛЛЕКТ.md](../ЭТАП-7-КОЛЛЕКТИВНЫЙ-ИНТЕЛЛЕКТ.md) (α=+2) — стратегия повышения VT
- [../collective_network/validation_report.md](../collective_network/validation_report.md) (α=+1) — валидация эффективности
- [../МЕТРИКИ-ЗДОРОВЬЯ.md](../МЕТРИКИ-ЗДОРОВЬЯ.md) (α=+2) — метрика VT

### История версий

- **v0.5** — первая версия, обогащение корневых документов (+5.52% VT)
- **v0.6** — расширение на поддиректории (-3.02% VT из-за ошибок классификации)
- **v0.7** — исправление через EXPLICIT_RULES (+3.57% VT)

### Классификация документов

**Уровни абстракции (α):**
- **+4**: Онтология, фундаментальные основания
- **+3**: Философия, мета-принципы
- **+2**: Законы, теория, методология
- **+1**: Методология, концепции
- **0**: Архитектура, мостовые документы
- **-1**: Спецификации, руководства
- **-2**: Примеры, шаблоны
- **-3**: Конфигурации
- **-4**: Исполняемый код

### Ключевые компоненты

- `EXPLICIT_RULES` — явные правила классификации
- `classify_document()` — определение α по содержимому
- `enrich_document()` — добавление метаданных

### Использование

```bash
python3 tools/enrich_alpha.py
# Автоматически обогащает документы без α-уровня
```

⇓ **Реализация:** [enrich_alpha.py](enrich_alpha.py)

## Использование инструментов в workflow

### Типичный цикл улучшения проекта

1. **Измерение:**
   ```bash
   python3 tools/health_metrics.py
   ```

2. **Диагностика:**
   ```bash
   python3 tools/self_improvement.py
   # Изучить self_improvement_report.txt
   ```

3. **Улучшение:**
   - Следовать рекомендациям из отчёта
   - Добавить связи, создать документы, переклассифицировать

4. **Обогащение:**
   ```bash
   python3 tools/enrich_alpha.py
   ```

5. **Повторное измерение:**
   ```bash
   python3 tools/health_metrics.py
   ```

6. **Сохранение истории:**
   ```bash
   python3 tools/save_metrics.py
   ```

7. **Визуализация:**
   ```bash
   python3 tools/visualize_connections.py
   ```
