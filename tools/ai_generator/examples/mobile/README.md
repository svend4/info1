# Mobile Development Examples

Examples for React Native, SwiftUI, Jetpack Compose, Flutter, and Kotlin Multiplatform.

## Examples

**File:** `examples.py`

- React Native app generation (TypeScript, Redux)
- SwiftUI iOS apps (MVVM, Combine)
- Jetpack Compose Android apps (Kotlin, Hilt)
- Flutter cross-platform apps (BLoC, GetX)
- Kotlin Multiplatform shared logic

**Run:** `python examples.py`
