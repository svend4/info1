# DevOps Excellence Examples

Examples for GitOps, IaC, observability, and policy as code.

## Examples

**File:** `examples.py`

- GitOps configuration (ArgoCD, FluxCD)
- Infrastructure as Code (Pulumi, Terraform, AWS CDK)
- Observability stack (Prometheus, Grafana, Loki, Jaeger)
- Policy as Code (OPA, Kyverno, Gatekeeper)

**Run:** `python examples.py`
