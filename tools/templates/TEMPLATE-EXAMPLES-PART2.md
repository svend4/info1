## 🏛️ Government Project — Пример госпроекта

### Проект: Внедрение электронных госуслуг для малого бизнеса

**Команда создания:**
```bash
python tools/project_template_generator.py --name e-gov-small-business --type government --git --ci
```

### Краткий пример POLICY-PROPOSAL (сжатая версия)

```markdown
# Программа "Бизнес Онлайн": Цифровизация услуг для МСП

## Проблема
- 6 млн МСП тратят 45 дней на получение лицензий
- 12+ визитов в госорганы для открытия бизнеса
- Ущерб экономике: 150 млрд ₽/год

## Решение
Единая цифровая платформа для 15 ключевых госуслуг онлайн

## KPI (3 года)
- Сокращение времени на 70% (45 → 14 дней)
- 4 млн пользователей
- Экономический эффект: 100 млрд ₽/год

## Бюджет: 2.4 млрд ₽ (2026-2028)
```

### Чек-лист для Government проекта
- [ ] Проблема с данными
- [ ] Измеримые KPI
- [ ] 3-летний план
- [ ] Детальный бюджет
- [ ] Общественные консультации

### Проект: Программа помощи бездомным животным "Второй шанс"

**Команда создания:**
```bash
python tools/project_template_generator.py --name animal-shelter-program --type nonprofit --git
```

### Краткий пример GRANT-PROPOSAL

```markdown
# Грант: "Второй шанс" — Программа реабилитации бездомных животных

## Проблема
- 50,000 бездомных животных в Москве
- Приюты переполнены на 150%
- 2 млн животных усыпляется ежегодно в России

## Цель
Спасти, реабилитировать и пристроить 300 животных за 12 месяцев

## Программа
1. Спасение и ветпомощь (стерилизация, вакцинация)
2. Реабилитация (социализация, подготовка к семье)
3. Пристройство (тщательный отбор, сопровождение)
4. Образование (уроки доброты для 2,000 детей)

## Бюджет: 11.09 млн ₽
- Персонал (9 чел.): 5.58M
- Ветеринария: 2.4M
- Содержание: 1.2M
- Инфраструктура: 1.44M

## Результаты
- 250 животных пристроено (83%)
- 2,000 детей обучено
- 50 волонтёров
```

### Проект: Производство биоразлагаемой упаковки "EcoPack"

**Команда создания:**
```bash
python tools/project_template_generator.py --name eco-packaging-plant --type manufacturing --git --ci
```

### Краткий пример PRODUCTION-PLAN

```markdown
# План производства: Биоразлагаемая упаковка из багассы

## Продукт
- Тарелки, контейнеры, стаканы, приборы
- Материал: Жмых сахарного тростника + крахмал
- Биоразлагаемость: 90 дней

## Производственная мощность (Year 1, 60% загрузка)
- Тарелки: 1.8M шт/год
- Контейнеры: 900K шт/год
- Стаканы: 1.44M шт/год
- Приборы: 2.7M шт/год

## Технология
1. Измельчение багассы
2. Смешивание с крахмалом
3. Горячее прессование (150°C)
4. Сушка и упаковка

## Оборудование: 13M₽
- Пресс-формы (автомат): 6M
- Измельчитель: 1.5M
- Сушильная камера: 1.2M
- Прочее: 4.3M

## Финансы (Year 1)
- Выручка: 30.3M₽
- OpEx: 53.9M₽
- Убыток: -27.5M₽ (Break-even Year 3)

## Инвестиции: 27.5M₽
- Собственные: 10M
- Кредит: 17.5M (15% годовых)
```

- [ ] Продукт определён

### Проект: Бутик-отель "Городские легенды"

**Команда создания:**
```bash
python tools/project_template_generator.py --name urban-legends-hotel --type hospitality --git
```

### Пример SERVICE-STANDARDS

```markdown
# Стандарты обслуживания: Бутик-отель "Городские легенды"

## Концепция
20 номеров, каждый в стиле определённой эпохи Москвы (1900-е, 1960-е, 2000-е)

## Целевая аудитория
- Туристы (30-50 лет, доход >100K₽/мес)
- Бизнес-путешественники
- Пары (романтические выходные)

## Стандарты

### Check-in (макс. 5 минут)
1. Приветствие по имени
2. Welcome drink (выбор из 3 вариантов)
3. Рассказ об истории номера (2 мин)
4. Сопровождение в номер

### Обслуживание номеров
- Уборка: 2 раза/день
- Смена белья: ежедневно
- Minibar: пополнение каждый вечер
- Turndown service: 19:00-21:00

### Ресторан
- Завтрак: 07:00-11:00 (шведский стол + à la carte)
- Room service: 24/7
- Время подачи: макс. 30 мин

### Гостевой опыт
- Персонализированные рекомендации (карта с маршрутами)
- Библиотека книг об истории Москвы
- Вечерние экскурсии (бесплатно для гостей)

## Ценообразование
- Стандарт: 8,000₽/ночь
- Deluxe: 12,000₽
- Suite: 18,000₽

## Занятость (прогноз Year 1)
- Средняя: 65%
- Выручка: 42M₽/год
- RevPAR: 6,500₽
```

## 🛒 Retail Project — Пример розничного проекта

### Проект: Сеть магазинов Zero Waste

**Команда создания:**
```bash
python tools/project_template_generator.py --name zero-waste-stores --type retail --git --ci
```

### Пример MERCHANDISING-PLAN

```markdown
# План мерчандайзинга: Магазин Zero Waste

## Концепция
Магазин товаров без упаковки (bulk) + экотовары многоразового использования

## Ассортимент (1,200 SKU)

### Продукты (60%, bulk)
- Крупы, макароны: 150 видов
- Орехи, сухофрукты: 80 видов
- Специи: 120 видов
- Масла, уксусы: 40 видов
- Моющие средства (bulk): 30 видов

### Экотовары (40%)
- Многоразовые пакеты, сумки
- Бамбуковые зубные щётки
- Металлические трубочки
- Пчелиный воск (вместо пластиковой плёнки)

## Планировка магазина (150 м²)

### Зона входа (20 м²)
- Весы для многоразовых контейнеров
- Стенд с инструкциями
- POS-терминал

### Bulk зона (80 м²)
- Диспенсеры (гравитационные, 200 шт)
- Высота полок: 160см
- Проходы: 120см

### Экотовары (30 м²)
- Открытые стеллажи
- Зона демонстрации (как использовать)

### Касса и упаковка (20 м²)
- 2 кассы
- Зона упаковки (многоразовые контейнеры, бумажные пакеты)

## Customer Journey

1. **Вход:** Взвешивание своих контейнеров (тара вычитается)
2. **Выбор:** Наполнение из диспенсеров
3. **Взвешивание:** На весах зоны (автоматический ценник)
4. **Касса:** Оплата (средний чек 1,200₽)
5. **Выход:** Упаковка в свои контейнеры

## Ценообразование (наценка 45%)
- Крупы: 150-400₽/кг
- Орехи: 800-1,500₽/кг
- Специи: 300-2,000₽/кг
- Экотовары: Премиум сегмент (+30% к аналогам)

## Метрики (Year 1)
- Трафик: 150 посетителей/день
- Conversion: 60%
- Средний чек: 1,200₽
- Выручка: 3,900₽/день × 300 дней = 11.7M₽

## Управление запасами
- Поставки: 2 раза/неделю
- Оборачиваемость: 14 дней
- Списание (просрочка): <1%
```

### Чек-лист для Retail проекта

## 🎯 Hobby Project — Пример хобби-проекта

### Проект: Блог о путешествиях "Медленные маршруты"

**Команда создания:**
```bash
python tools/project_template_generator.py --name slow-travel-blog --type hobby --git
```

### Пример PROJECT-ROADMAP

```markdown
# Roadmap: Блог "Медленные маршруты"

## Концепция
Блог о путешествиях без самолётов — только поезда, автобусы, паромы.
Философия: Slow travel, местная культура, экологичность.

## Цели (12 месяцев)
- 50 статей (маршруты по России и Европе)
- 10,000 подписчиков в Instagram
- 5,000 уникальных посетителей/месяц на сайте
- Монетизация: 50,000₽/месяц (к концу года)

## Контент-план

### Рубрики
1. **Маршруты** (30 статей):
   - Москва — Владивосток (Транссиб, 14 дней)
   - Санкт-Петербург — Стамбул (поезд + паром)
   - Балтийское кольцо (Рига — Таллин — Хельсинки)

2. **Гайды** (10 статей):
   - Как спланировать путешествие без самолёта
   - Лучшие ж/д маршруты Европы
   - Бюджет: 30,000₽ на 2 недели

3. **Истории** (10 статей):
   - Встречи с местными жителями
   - Неожиданные открытия

## Timeline

### Месяцы 1-3: Запуск
- [x] Создать сайт (WordPress + тема)
- [x] Дизайн логотипа и фирменный стиль
- [x] Первые 10 статей (из архива путешествий)
- [ ] Запуск Instagram (3 поста/неделю)

### Месяцы 4-6: Рост
- [ ] 20 новых статей
- [ ] Первое путешествие для блога (Казань — Екатеринбург)
- [ ] Коллаборация с 5 блогерами (guest posts)
- [ ] Email рассылка (500 подписчиков)

### Месяцы 7-9: Монетизация
- [ ] Партнёрская программа (РЖД, Booking.com)
- [ ] Первые рекламные посты (10,000₽/пост)
- [ ] Продажа PDF-гайдов (500₽/шт, 50 продаж)

### Месяцы 10-12: Масштабирование
- [ ] YouTube канал (видео-обзоры маршрутов)
- [ ] Patreon (эксклюзивный контент для патронов)
- [ ] Достижение 10K подписчиков

## Бюджет (первые 6 месяцев)

| Статья | Сумма (₽) |
|--------|-----------|
| Домен и хостинг | 3,000 |
| Премиум тема WordPress | 5,000 |
| Фотостоки (подписка) | 6,000 |
| Реклама в соцсетях | 15,000 |
| Путешествия (контент) | 50,000 |
| **Итого** | **79,000** |

**Источник:** Собственные средства

## Метрики успеха

**Квартал 1:**
- [ ] 1,000 подписчиков Instagram
- [ ] 1,000 посетителей/месяц на сайте
- [ ] 10 статей опубликовано

**Квартал 2:**
- [ ] 3,000 подписчиков
- [ ] 2,500 посетителей/месяц
- [ ] Первый доход (партнёрки): 5,000₽

**Квартал 3:**
- [ ] 6,000 подписчиков
- [ ] 4,000 посетителей/месяц
- [ ] Доход: 20,000₽/месяц

**Квартал 4:**
- [ ] 10,000 подписчиков
- [ ] 5,000 посетителей/месяц
- [ ] Доход: 50,000₽/месяц

## Инструменты

**Создание контента:**
- WordPress (сайт)
- Canva (графика)
- Lightroom (обработка фото)
- Google Docs (написание статей)

**Продвижение:**
- Instagram, Pinterest
- SEO (Yoast plugin)
- Email (Mailchimp)

**Аналитика:**
- Google Analytics
- Instagram Insights
- Яндекс.Метрика

## Риски
- Недостаток времени (работа full-time) → Планирование контента заранее
- Выгорание → Не пытаться постить каждый день
- Низкая вовлечённость → Фокус на качество, а не количество

## Долгосрочная vision (2-3 года)
- Книга о slow travel
- Организация групповых путешествий
- Превращение в full-time работу
```
