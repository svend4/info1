## 💻 1. Software Project

### Начало проекта
- [ ] Определены требования (functional & non-functional)
- [ ] Выбран архитектурный стиль (monolith/microservices/serverless)
- [ ] Выбран tech stack (frontend, backend, database)
- [ ] Настроена система контроля версий (Git)
- [ ] Создан репозиторий на GitHub/GitLab
- [ ] Настроен CI/CD pipeline
- [ ] Определена стратегия тестирования (unit/integration/e2e)

### Разработка

- [ ] Созданы API спецификации (OpenAPI/Swagger)
- [ ] Настроен linting и formatting (ESLint, Prettier, etc.)
- [ ] Написаны unit tests (80%+ coverage)
- [ ] Настроен monitoring и logging
- [ ] Проведён code review
- [ ] Обновлён README с инструкциями

### Развертывание

- [ ] Настроен production deployment
- [ ] Настроены alerts и monitoring

## 📊 Как использовать чек-листы

### 1. Выберите свой тип проекта
Найдите соответствующий раздел в этом документе.

### 2. Проходите чек-лист поэтапно
Отмечайте выполненные пункты по мере продвижения проекта.

### 3. Адаптируйте под свои нужды
Добавьте специфичные для вашего проекта пункты.

### 4. Отслеживайте прогресс
Используйте чек-лист для tracking завершенности проекта.

### 5. Делитесь с командой
Используйте чек-лист для alignment команды.
