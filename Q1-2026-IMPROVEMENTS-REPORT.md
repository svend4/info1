**Файл:** `tools/project_template_generator.py` (улучшено ~300 строк)

**Что сделано:**

**1. Пошаговая структура**
- Шаг 1: Выбор типа проекта
- Шаг 2: Метаданные проекта
- Шаг 3: Интеграции и инструменты
- Шаг 4: Превью структуры
- Итог: Финальное подтверждение

**2. Категоризация типов проектов**
Группировка по 5 категориям:
- Технические (software, research)
- Бизнес и управление (business, finance, government, nonprofit)
- Производство (manufacturing, agriculture)
- Образование и здоровье (education, healthcare)
- Креативные и сервис (legal, arts, sports, hospitality, retail, hobby)

**3. Визуальные улучшения**
- Иконки для каждого типа (💻🏥🌾💰📚...)
- Индикаторы статуса (✓ Да, ○ Нет)
- Стрелки для ввода (→)
- Разделители секций (─, =)
- Улучшенная читаемость

**4. Новый функционал**

**4.1 Метаданные проекта:**
```
→ Введите описание проекта (опционально):
  [ввод пользователя]
✓ Описание сохранено

→ Автор проекта (опционально):
  [ввод пользователя]
✓ Автор: [имя]
```

**4.2 Превью структуры:**
```

  project-name/                            # корневая директория
  ├── 01-Концепция/                        # концептуальные документы (α=+1)
  ├── 02-Архитектура/                      # архитектурные решения (α=0)
  ├── 03-Реализация/                       # реализация проекта (α=-1)
  ├── docs/                                # документация (α=-2)
  ...
  [domain-specific папки]
  ...

  📊 Итого: ~12 папок, ~8+ файлов

**4.3 Помощь и документация:**
```

  • Чек-листы проектов: tools/templates/PROJECT-CHECKLISTS.md
