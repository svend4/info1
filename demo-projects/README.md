## 🚀 Создание своего проекта

### Используя генератор

```bash
python tools/project_template_generator.py \
  --name my-project \
  --type <domain> \
  --output demo-projects
```

**Доступные домены:**
- software, research, business, education
- legal, healthcare, arts, finance
- government, nonprofit, manufacturing, agriculture
- sports, hospitality, retail, hobby

**Всего: 16 типов** (100% покрытие) 🏆

### С дополнительными опциями

```bash
python tools/project_template_generator.py \
  --name my-project \
  --type software \
  --output . \
  --git \
  --ci \
  --security
```

**Опции:**
- `--git` — инициализировать git
- `--ci` — добавить CI/CD workflows
- `--security` — добавить security tools
- `--quality` — добавить code quality tools
- `--interactive` — интерактивный режим
