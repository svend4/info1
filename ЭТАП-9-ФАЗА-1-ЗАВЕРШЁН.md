## 🔧 Технические детали

### Rule-based Classifier

**Алгоритм:**
1. Токенизация описания
2. Подсчёт совпадений с keywords для каждого типа
3. Взвешивание по weight параметру
4. Нормализация scores к [0, 1]
5. Выбор топ-3 типов с confidence >0.3

**Преимущества:**
- ✅ Быстрая работа (<1 мс)
- ✅ Не требует обучающих данных
- ✅ Простота отладки

**Недостатки:**
- ❌ Ограниченная точность (75%)
- ❌ Не понимает контекст
- ❌ Чувствителен к формулировкам

## 💡 Ключевые инсайты

### 1. Rule-based достаточно для прототипа

75% точности - хороший результат для rule-based подхода. Этого достаточно для MVP и демонстрации концепции.

### 2. Multi-domain работает

Система успешно определяет проекты с несколькими типами (например, healthcare + business).

### 3. Параметры извлекаются корректно

Бюджет, timeline, team size извлекаются с высокой точностью через regex.

### 4. Software keywords конфликтуют

"Система", "управление", "онлайн" - слишком общие слова, которые есть во многих доменах. Для Фазы 2 нужен context-aware подход.
