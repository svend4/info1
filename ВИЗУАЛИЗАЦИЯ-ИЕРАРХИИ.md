## Горизонтальные связи (на одном уровне)

### На уровне α=0 (Концепции)

```
02-Информационная    ←→   03-Робототехника    ←→   04-Бытовые-циклы
      система
      (Карточки)           (Роботы используют           (Циклы организованы
                            карточки для задач)          через карточки)
         ↕                          ↕                          ↕
    ИНТЕГРАЦИЯ:
    • Роботам назначаются задачи из карточек
    • Циклы создают повторяющиеся карточки
    • Карточки хранят результаты работы роботов
```

## Путь от онтологии до кода (конкретный пример)

```
Как метаметапринцип становится работающим кодом:

α=+4: ОНТОЛОГИЯ
      "Зависимость от наблюдателя"
      Система существует для ЧЕЛОВЕКА, наблюдатель определяет систему
                    ⇓
α=+3: ФИЛОСОФИЯ
      "Достоинство и гуманность"
      Технология служит жизни, человек = цель (не средство)
                    ⇓
α=+2: ЗАКОН
      "Закон человеко-центричности"
      D_max при K_человечность > K_автоматизация
      Достоинство максимально, когда человечность > автоматизации
                    ⇓
α=+1: ПРИНЦИП
      "Принцип человеко-центричности"
      • Технология усиливает способности, не заменяет человека
      • Уважает выбор и автономию
      • Не инфантилизирует
                    ⇓
α=0:  КОНЦЕПЦИЯ
      Система для пожилых людей:
      • Карточки (информация доступна и понятна)
      • Роботы (помощники, не замена)
      • Циклы (снижают когнитивную нагрузку)
                    ⇓
α=-1: СПЕЦИФИКАЦИЯ
      • YAML+Markdown (текстовый формат, читаемый человеком)
      • Теги на русском языке
      • Простая иерархия (не более 4 уровней)
      • emergency_contact (приоритет человеческой помощи)
                    ⇓
α=-2: ШАБЛОН
      Шаблон карточки-лекарства с полями:
      • medication (что принимать — понятно)
      • administration (как принимать — инструкция)
      • side_effects (что ожидать — прозрачность)
                    ⇓
α=-3: ПРИМЕР
      Эналаприл 10мг:
      ---
      title: "Эналаприл 10мг"
      medication:
        name: "Эналаприл"
        dosage: "10 мг"
      administration:
        frequency: "1 раз в день"
        time: ["19:00"]
        instructions: "Запить полным стаканом воды"
      ---
      # Что делать при пропуске
      Если пропустили: принять как вспомнили (если < 12 часов)
      НЕ принимать двойную дозу!
                    ⇓
α=-4: КОД
      class MedicineCard(Card):
          medication: Dict
          administration: Dict

          def schedule_reminder(self):
              """Создать напоминание с учётом человека"""
              # НЕ просто alarm в 19:00
              # А: напоминание за 15 мин + звук + текст +
              #    + опция "отложить" + история пропусков
              reminder = Reminder(
                  time=self.administration['time'][0],
                  advance_warning=15,  # за 15 мин
                  allow_postpone=True,  # можно отложить
                  escalate_if_missed=True,  # позвонить дочери если пропуск
                  human_readable_message=f"Пора принять {self.medication['name']}"
              )
              return reminder

РЕЗУЛЬТАТ на выходе: Бабушка получает напоминание "Пора принять Эналаприл"
за 15 минут до времени, может отложить если занята, система позвонит дочери
если пропустит. ВСЁ это — реализация метаметапринципа "Зависимость от наблюдателя"
через 8 уровней абстракции!
```
