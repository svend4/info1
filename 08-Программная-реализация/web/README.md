## Описание

Современный веб-интерфейс для управления домашней информационной системой карточек. Реализован как **Single Page Application (SPA)** с использованием чистого HTML/CSS/JavaScript без фреймворков.

### Возможности

- ✅ **Просмотр карточек** — все типы карточек в одном месте
- ➕ **Создание** — простая форма для добавления новых карточек
- ✏️ **Редактирование** — изменение существующих карточек
- 🗑️ **Удаление** — с подтверждением
- 🔍 **Поиск** — по названию и описанию
- 🎯 **Фильтры** — по статусу, приоритету, типу
- 📊 **Статистика** — в реальном времени
- 📱 **Адаптивность** — работает на всех устройствах

### Типы карточек

- ✓ Задачи
- 💊 Лекарства
- 👤 Контакты
- 📅 Встречи
- 🛒 Покупки
- 📝 Заметки
- 📁 Проекты

## Быстрый старт

### Шаг 1: Запуск API сервера

Веб-интерфейс требует запущенного Flask API сервера:

```bash
# Из корня проекта
cd 08-Программная-реализация
python3 examples/flask_api_example.py
```

API будет доступен по адресу: `http://localhost:5000`

### Шаг 2: Открыть веб-интерфейс

```bash
# Открыть в браузере
cd web
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows
```

Или через простой HTTP сервер (рекомендуется):

```bash
# Python 3
python3 -m http.server 8080

# Затем открыть в браузере
# http://localhost:8080
```

## API Endpoints

Веб-интерфейс использует следующие endpoints:

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/api/cards` | Получить все карточки |
| GET | `/api/cards/:id` | Получить карточку по ID |
| POST | `/api/cards` | Создать карточку |
| PUT | `/api/cards/:id` | Обновить карточку |
| DELETE | `/api/cards/:id` | Удалить карточку |
| GET | `/api/stats` | Получить статистику |

## Конфигурация

### Изменение адреса API

По умолчанию веб-интерфейс подключается к `http://localhost:5000/api`.

Чтобы изменить адрес, отредактируйте `app.js`:

```javascript
// Найти строку:
const API_BASE_URL = 'http://localhost:5000/api';

// Изменить на:
const API_BASE_URL = 'http://your-server.com:5000/api';
```

### CORS

Если API и веб-интерфейс находятся на разных доменах, убедитесь, что в Flask API включен CORS:

```python
from flask_cors import CORS
app = Flask(__name__)
CORS(app)  # Разрешить все origins
```

- **JavaScript (ES6+)** — async/await, модули, стрелочные функции

### Добавление нового типа карточки

1. **Добавить в navigation** (`index.html`):
```html
<button class="nav-btn" data-view="newtype">🆕 Новый тип</button>
```

2. **Добавить иконку** (`app.js`, функция `createCardHTML`):
```javascript
const typeIcons = {
    // ...
    newtype: '🆕',
};
```

3. **Добавить динамические поля** (`app.js`, функция `renderDynamicFields`):
```javascript
if (type === 'newtype') {
    container.innerHTML += `
        <div class="form-group">
            <label for="cardCustomField">Кастомное поле</label>
            <input type="text" id="cardCustomField">
        </div>
    `;
}
```

## Безопасность

### Реализованные меры

- ✅ **HTML escaping** — все пользовательские данные экранируются
- ✅ **HTTPS recommended** — используйте HTTPS в production
- ✅ **CORS** — настроен только для разрешенных origins
- ✅ **Валидация** — на клиенте и сервере

### Рекомендации

1. **Аутентификация:** Добавьте JWT или session-based auth
2. **Rate limiting:** Ограничьте количество запросов
3. **Input validation:** Проверяйте все данные на сервере
4. **HTTPS:** Используйте SSL/TLS в production

## Устранение неполадок

### Проблема: "Не удалось загрузить карточки"

**Причина:** API сервер не запущен или недоступен

**Решение:**
```bash
# Проверить, что API запущен
curl http://localhost:5000/api/cards

# Если нет, запустить
python3 examples/flask_api_example.py
```

### Проблема: CORS ошибка в консоли

**Причина:** Браузер блокирует cross-origin запросы

**Решение:**
1. Запустить API с CORS:
```python
from flask_cors import CORS
CORS(app)
```

2. Или открыть HTML через HTTP сервер, а не file://

### Проблема: Модальное окно не закрывается

**Причина:** JavaScript ошибка

**Решение:** Открыть консоль разработчика (F12) и проверить ошибки
