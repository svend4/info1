# Бытовые циклы и задания

## Философия циклического подхода

### Почему циклы важны?

**Для всех людей:**
- Предсказуемость и структура жизни
- Снижение когнитивной нагрузки (не нужно каждый раз думать)
- Формирование полезных привычек
- Эффективное использование времени
- Меньше стресса от забытых дел

**Особенно для пожилых людей:**
- Поддержание ритма жизни
- Профилактика когнитивных нарушений (регулярность полезна для мозга)
- Чувство контроля над жизнью
- Социальная активность (регулярные встречи, звонки)
- Здоровье (регулярный прием лекарств, процедуры)

### Принцип работы

```
Цикл = Повторяющаяся последовательность задач

Дневной цикл (24 часа)
  ↓ 7 повторений
Недельный цикл (7 дней)
  ↓ 4 повторения
Месячный цикл (30 дней)
  ↓ 12 повторений
Годовой цикл (365 дней)
  ↓ Повторяется годами
Жизненный паттерн
```

## Дневной цикл

### Типичный день пенсионера (шаблон)

#### 06:00-08:00 Утро

**06:30 Подъем**
```
┌─────────────────────────────────┐
│ Автоматика:                     │
│ - Постепенное осветление (15мин)│
│ - Открытие штор                 │
│ - Включение отопления в ванной  │
│ - Подогрев воды для чая         │
│                                 │
│ Робот-координатор:              │
│ - Приветствие                   │
│ - Сводка погоды                 │
│ - План дня                      │
│ - Напоминания                   │
└─────────────────────────────────┘
```

**06:45 Утренние процедуры**
```
Человек:
□ Умывание
□ Душ (по желанию)
□ Туалет
□ Гигиена
□ Легкая разминка/зарядка (опционально)

Помощь роботов:
- Робот-помощник: подать полотенце, тапочки
- Датчики: контроль безопасности в ванной (падение)
- Голосовой ассистент: музыка, новости
```

**07:00 Измерение показателей здоровья**
```
□ Давление (автоматический тонометр)
□ Температура (по необходимости)
□ Вес (раз в неделю)
□ Уровень сахара (для диабетиков)

Робот-компаньон:
- Напоминает о измерениях
- Записывает результаты
- Сравнивает с нормой
- При отклонениях: предупреждает или звонит врачу
```

**07:15 Завтрак**
```
Человек:
□ Приготовление завтрака (простого)
□ Прием пищи
□ Мытье посуды

Помощь:
- Умная плита: безопасное приготовление
- Робот-кухонный помощник: подать продукты
- Умная кофеварка: автоматический кофе
- Робот-уборщик: убрать крошки

Типичное меню:
- Каша/омлет/бутерброды
- Чай/кофе
- Фрукты
```

**07:45 Прием лекарств**
```
КРИТИЧЕСКИ ВАЖНО!

Система напоминаний:
1. За 10 минут: предупреждение
2. В момент приема: голосовое напоминание
3. Через 10 минут: проверка (принято?)

Умная таблетница:
- Отсеки с лекарствами на день/неделю
- Световая индикация
- Звуковой сигнал
- Подтверждение приема (кнопка)

Лекарства записаны в карточках:
┌────────────────────────────────┐
│ Утро (07:45):                  │
│ □ Таблетка от давления (10мг)  │
│ □ Витамин D                    │
│ □ Аспирин (если назначено)     │
└────────────────────────────────┘

Если не принято → уведомление родственникам
```

#### 08:00-12:00 Первая половина дня

**08:00 Легкая уборка**
```
Человек:
□ Застелить постель
□ Открыть окно (проветривание)
□ Убрать вещи на места

Роботы работают АВТОМАТИЧЕСКИ:
- Робот-пылесос: пройти по комнатам (20 мин)
- Робот-мойщик: протереть пол на кухне (15 мин)
- Работают пока человек занят другим

Условие запуска: человек вышел из комнаты
```

**09:00 Свободное время / Активности**
```
Варианты:
□ Прогулка (30-60 минут)
□ Чтение книги/газеты
□ Просмотр телевизора
□ Хобби (вязание, рисование, пазлы)
□ Звонок друзьям/родственникам
□ Работа в саду (если есть)
□ Уход за комнатными растениями

Робот-компаньон:
- Может составить компанию
- Включить музыку/аудиокнигу
- Напомнить о встрече
- Позвонить по видеосвязи родственникам
```

**11:00 Второй завтрак / Перекус**
```
□ Фрукты
□ Йогурт
□ Чай/сок
□ Печенье

Робот: напоминание о перекусе
```

#### 12:00-17:00 День

**12:00 Обед (главный прием пищи)**
```
Приготовление обеда:
□ Достать продукты
□ Приготовить блюда (30-60 мин)
□ Накрыть на стол

Помощь:
- Робот-кухонный помощник:
  * Подать продукты из холодильника
  * Помочь с нарезкой (автоматическая нарезка)
  * Перемешивание в кастрюле
  * Мытье посуды после

- Умная плита:
  * Контроль температуры
  * Автоотключение
  * Уведомление о готовности

- Голосовой помощник:
  * Рецепты на экране
  * Таймеры

Типичное меню:
- Суп
- Второе блюдо (мясо/рыба + гарнир)
- Салат
- Компот/чай
```

**13:00 Прием пищи**
```
□ Обед
□ Общение (если есть с кем)
□ Просмотр телевизора/слушание радио
```

**14:00 Прием лекарств (послеобеденный)**
```
□ Лекарства по расписанию
Напоминание от системы
```

**14:30 Дневной отдых**
```
Рекомендуется для пожилых:
□ Дневной сон (30-60 мин) ИЛИ
□ Отдых лежа/сидя
□ Спокойное чтение

Автоматика:
- Приглушить свет
- Закрыть шторы
- Тишина (отключить звонки)
- Комфортная температура

Мониторинг:
- Датчики дыхания (контроль)
- Экстренная связь доступна
```

**15:30 Полдник**
```
□ Чай/кофе
□ Выпечка/фрукты
```

**16:00 Вторая активность**
```
□ Хобби
□ Прогулка
□ Общение (друзья, соседи)
□ Покупки (если нужно)
□ Посещение поликлиники (по расписанию)

Робот-наблюдатель:
- Если человек ушел из дома → уведомление родственникам (опционально)
- Отслеживание времени отсутствия
- Если долго не возвращается → звонок
```

#### 17:00-22:00 Вечер

**17:00 Возвращение домой / Подготовка ужина**
```
□ Проверка списка покупок (что купить завтра)
□ Подготовка продуктов для ужина

Роботы (пока человека не было):
- Полили растения
- Сделали уборку
- Проверили почту
- Подготовили отчет о доме
```

**18:00 Ужин**
```
Легкий ужин:
□ Каша/творог/рыба
□ Овощи
□ Чай
□ Избегать тяжелой пищи

Помощь роботов: аналогично обеду
```

**19:00 Прием лекарств (вечерний)**
```
□ Вечерние лекарства
□ Измерение давления (по показаниям)
```

**19:30 Вечерние дела**
```
□ Мытье посуды
□ Легкая уборка кухни
□ Подготовка одежды на завтра
□ Проверка дверей/окон

Роботы:
- Робот-наблюдатель: обход дома (безопасность)
- Проверка замков
- Выключение ненужных приборов
```

**20:00 Вечерний отдых**
```
□ Телевизор (любимые программы)
□ Чтение
□ Общение с семьей (звонки, видеосвязь)
□ Настольные игры
□ Рукоделие

Робот-компаньон:
- Может составить компанию
- Включить любимую программу
- Помочь с видеозвонком внукам
- Почитать вслух
```

**21:00 Подготовка ко сну**
```
□ Легкий перекус (при желании)
□ Проверка заданий на завтра
□ Планирование следующего дня
```

**21:30 Вечерние процедуры**
```
□ Умывание
□ Гигиена
□ Переодевание в пижаму

Автоматика:
- Подогрев ванной комнаты
- Включение ночника
- Приглушение освещения в доме
```

**22:00 Сон**
```
Автоматика:
- Выключение основного света
- Ночник в коридоре (безопасность)
- Закрытие штор
- Оптимальная температура для сна
- Белый шум (опционально)

Мониторинг:
- Датчики движения (обнаружение подъемов)
- Экстренная кнопка у кровати
- Автоматический ночник (если встал)
- Контроль дыхания (опционально)

Если ночью встает:
- Автоматическое освещение пути в туалет
- Робот-помощник на страже (падение)
```

### Варианты дневных циклов

#### Будний день vs Выходной

**Будний день:**
- Более структурированный
- Больше активностей
- Регулярные задачи
- Возможны визиты (врач, магазин)

**Выходной:**
- Более расслабленный
- Возможность поспать дольше
- Посещение родственников
- Более длительные прогулки
- Особые активности (кино, парк)

#### Летний день vs Зимний день

**Летний день:**
- Больше времени на улице
- Работа в саду/огороде
- Ранний подъем (светло рано)
- Легкая пища

**Зимний день:**
- Больше времени дома
- Позже подъем (темно утром)
- Раньше ужин (темнеет рано)
- Более сытная пища
- Контроль отопления

## Недельный цикл

### Типичная неделя

#### Понедельник
```
Тема: Начало недели, планирование

Особые задачи:
□ Планирование на неделю
□ Проверка календаря
□ Оплата счетов (если нужно)
□ Звонок родственникам (регулярный)

Уборка:
□ Спальня (смена белья)

Покупки:
□ Проверка запасов на неделю
```

#### Вторник
```
Тема: Активный день

Особые задачи:
□ Поликлиника (если по расписанию)
□ Аптека (покупка лекарств)
□ Встреча с друзьями (опционально)

Уборка:
□ Гостиная

Активности:
□ Прогулка в парке
□ Библиотека
```

#### Среда
```
Тема: День стирки и уборки

Особые задачи:
□ Большая стирка
□ Глажка (частичная)
□ Уборка ванной комнаты

Робот-прачка:
- Собрать белье
- Загрузить стиральную машину
- Развесить
- (Глажка - человек или робот)

Покупки:
□ Свежий хлеб, молоко
```

#### Четверг
```
Тема: Хозяйственный день

Особые задачи:
□ Уборка кухни (генеральная)
□ Ревизия холодильника
□ Выбросить просроченное
□ Полить комнатные растения

Робот-садовник:
- Автоматический полив всех растений
- Проверка состояния
- Рапорт о проблемах
```

#### Пятница
```
Тема: Подготовка к выходным, покупки

Особые задачи:
□ Большие покупки продуктов на выходные
□ Закупка на неделю
□ Уборка прихожей
□ Подготовка дома к гостям (если планируются)

Список покупок:
- Автоматически сформирован на основе:
  * Закончившихся продуктов
  * Меню на следующую неделю
  * Предпочтений

Помощь:
□ Робот-помощник: может отправиться за покупками (футуристическая идея)
□ Или: заказ онлайн с доставкой
```

#### Суббота
```
Тема: Генеральная уборка, семья

Особые задачи:
□ Генеральная уборка дома
□ Смена постельного белья
□ Уборка всех комнат
□ Мытье полов

Роботы работают на полную:
- Все роботы-уборщики активны
- Параллельная работа в разных комнатах
- Человек контролирует и помогает

Семья:
□ Приезд детей/внуков (часто по выходным)
□ Совместный обед
□ Общение

Активности:
□ Рынок (свежие продукты)
□ Прогулка в парке с семьей
□ Культурные мероприятия
```

#### Воскресенье
```
Тема: Отдых, подготовка к неделе

Особые задачи:
□ Отдых
□ Церковь/храм (для верующих)
□ Семейный обед
□ Подготовка к новой неделе

Планирование:
□ Проверка календаря на неделю
□ Врачи, встречи
□ Меню на неделю
□ Список задач

Легкая уборка:
□ Поддержание порядка
□ Стирка (если нужно)

Вечер воскресенья:
□ Подготовка одежды на понедельник
□ Раннее время сна (готовность к неделе)
```

### Специальные недельные задачи

**Каждую неделю обязательно:**
```
□ Звонок всем детям (распределено по дням)
□ Проверка давления 2 раза
□ Проверка веса (1 раз)
□ Ревизия лекарств (достаточно ли?)
□ Проверка счетов/финансов
□ Полив всех растений
□ Большая стирка + смена белья
□ Генеральная уборка (суббота)
□ Покупки продуктов
```

## Месячный цикл

### Регулярные месячные задачи

#### Начало месяца (1-5 число)
```
Финансы:
□ Получение пенсии
□ Оплата коммунальных услуг
□ Оплата интернета/телефона
□ Проверка баланса
□ Планирование расходов на месяц

Здоровье:
□ Покупка лекарств на месяц
□ Запись к врачам (если нужно)
□ Проверка графика приема врачей
```

#### Середина месяца (15-20 число)
```
Дом:
□ Генеральная уборка всего дома
□ Проверка бытовой техники
□ Замена фильтров (если нужно)
□ Ревизия запасов

Сад (если есть):
□ Сезонные работы
□ Проверка состояния растений
□ Удобрения
```

#### Конец месяца (25-30 число)
```
Планирование:
□ Анализ прошедшего месяца
□ Планирование следующего месяца
□ Проверка календаря
□ Дни рождения в следующем месяце

Подготовка:
□ Закупка недостающего
□ Подготовка к следующему сезону (если смена)
```

### Специальные месячные проверки

**Технические проверки:**
```
□ Проверка всех роботов (работоспособность)
□ Обновление ПО роботов
□ Проверка зарядных станций
□ Чистка роботов от пыли
□ Калибровка датчиков

□ Проверка умного дома:
  - Датчики дыма
  - Датчики утечки
  - Замки
  - Камеры
  - Освещение
```

**Дом:**
```
□ Проверка сантехники
□ Проверка электрики
□ Состояние окон/дверей
□ Вентиляция
□ Фильтры кондиционера
```

**Запасы:**
```
□ Проверка продуктов длительного хранения
□ Консервы (срок годности)
□ Бытовая химия
□ Туалетная бумага, мыло
□ Батарейки, лампочки
```

## Годовой цикл

### Зима (Декабрь-Февраль)

**Декабрь:**
```
Праздники:
□ Подготовка к Новому году
□ Покупка подарков
□ Украшение дома
□ Праздничное меню

Дом:
□ Проверка отопления
□ Утепление окон
□ Запас дров/угля (если есть печь)
□ Подготовка к морозам

Здоровье:
□ Вакцинация от гриппа
□ Витамин D (мало солнца)
□ Осторожность на льду
```

**Январь:**
```
Планирование года:
□ Цели на год
□ Медицинские осмотры (график)
□ Финансовое планирование
□ Календарь дней рождений

Дом:
□ Разбор после праздников
□ Инвентаризация
□ Планирование ремонта (если нужен)
```

**Февраль:**
```
Подготовка к весне:
□ Заказ семян (если огород)
□ Планирование посадок
□ Проверка садового инвентаря

Здоровье:
□ Конец сезона гриппа
□ Больше прогулок (день длиннее)
```

### Весна (Март-Май)

**Март:**
```
Дом:
□ Генеральная весенняя уборка
□ Мытье окон
□ Разбор гардероба (зима→весна)
□ Чистка ковров

Сад:
□ Подготовка почвы
□ Обрезка деревьев
□ Планирование клумб
```

**Апрель:**
```
Сад:
□ Посадка рассады
□ Подготовка грядок
□ Высадка раннихкультур

Дом:
□ Ревизия летних вещей
□ Упаковка зимних вещей
```

**Май:**
```
Сад:
□ Активная посадка
□ Полив
□ Прополка

Праздники:
□ День Победы
□ Майские праздники

Активность:
□ Больше прогулок
□ Пикники
□ Дача (если есть)
```

### Лето (Июнь-Август)

**Июнь-Август:**
```
Сад:
□ Полив (ежедневно в жару)
□ Прополка
□ Подкормка
□ Борьба с вредителями
□ Первый урожай (ягоды, зелень)

Дом:
□ Проверка кондиционера
□ Москитные сетки
□ Вентиляция

Здоровье:
```

## Автоматизация циклов

### Как система помогает

**Автоматическое создание задач:**
```
Система знает что:
- Каждый день в 7:45 → прием лекарств
- Каждую среду → стирка
- Каждую субботу → генеральная уборка
- 1 числа каждого месяца → оплата счетов
- Каждую весну → посадка огорода

Автоматически создает карточки-задания
Человек просто выполняет по списку
```

**Умные напоминания:**
```
- За день: "Завтра к врачу"
- За час: "Через час прием лекарств"
- В момент: "Время принять лекарства"
- После: "Вы приняли лекарства?"
```

**Адаптация:**
```
Система учится:
- В какое время человек обычно встает
- Когда предпочитает гулять
- Когда обычно звонит родственникам

Адаптирует напоминания под привычки
```

**Координация роботов:**
```
Человеку не нужно помнить:
- Когда поливать цветы (робот делает)
- Когда пылесосить (робот делает)
- Когда проверять дом (робот делает)

Человек фокусируется на важном:
- Здоровье
- Общение
- Хобби
- Отдых
```

## Гибкость системы

### Адаптация под индивидуальные потребности

**Корректировка времени:**
- "Сова" → все сдвигается на 2-3 часа позже
- "Жаворонок" → все раньше
- Проблемы со сном → индивидуальный график

**Состояние здоровья:**
- Плохое самочувствие → отмена несрочных задач
- Госпитализация → автопилот (роботы поддерживают дом)
- Восстановление → щадящий режим

**Особые события:**
- Гости → изменение распорядка
- Праздники → особый режим
- Поездка → дом в режиме отсутствия
