## Сценарий 1: Первый запуск

**Цель:** Установить систему и создать первые карточки за 10 минут.

**Кому:** Новые пользователи

### Шаг 1: Установка (3 минуты)

```bash
# 1. Клонировать репозиторий
git clone https://github.com/svend4/info1.git
cd info1

# 2. Перейти в директорию реализации
cd 08-Программная-реализация

# 3. Установить систему
pip install -e .

# 4. Проверить установку
card-cli --version
```

**Ожидаемый результат:**
```
card-cli version 1.0.0
```

### Шаг 2: Загрузка демо-данных (2 минуты)

```bash
# Создать демонстрационные карточки
cd card_system
python3 seed_data.py
```

**Что произойдет:**
- Создастся 23 карточки разных типов
- Задачи, лекарства, контакты, встречи, покупки, заметки
- Все с реалистичными данными

**Вывод:**
```
📋 Создание демонстрационных задач...
  ✓ Купить молоко
  ✓ Оплатить коммунальные услуги
  ...
✅ Создано 23 карточек
```

### Шаг 3: Просмотр карточек (2 минуты)

```bash
# Вернуться на уровень выше
cd ..

# Посмотреть все карточки
card-cli list

# Посмотреть только задачи
card-cli list --type task

# Посмотреть только лекарства
card-cli list --type medicine
```

**Результат:** Вы увидите список всех созданных карточек.

### Шаг 4: Запуск веб-интерфейса (3 минуты)

```bash
# Терминал 1: Запустить API
python3 examples/flask_api_example.py

# Терминал 2: Запустить веб-сервер
cd web
python3 -m http.server 8080
```

**Открыть в браузере:**
```
http://localhost:8080
```

**✅ Готово!** У вас работающая система с демо-данными.

## Сценарий 2: Утренняя рутина

**Цель:** Организовать ежедневную утреннюю проверку задач и лекарств.

**Кому:** Регулярные пользователи

### Утренний чек-лист

**1. Проверить задачи на сегодня**

```bash
# Все активные задачи
card-cli list --type task --status active

# С высоким приоритетом
card-cli list --type task --priority high
```

**2. Проверить лекарства на утро**

```bash
# Все активные лекарства
card-cli list --type medicine --status active

# Найти лекарство по расписанию "09:00"
card-cli search "09:00"
```

**3. Посмотреть встречи на сегодня**

```bash
# Все запланированные встречи
card-cli list --type meeting --status pending
```

### Создать новую задачу

```bash
# Быстрое создание
card-cli create task "Позвонить в поликлинику" \
  --priority high \
  --tags "здоровье,срочно"
```

### Отметить выполненное

```bash
# Найти ID задачи
card-cli list --type task

# Отметить как выполненную
card-cli update TASK_ID --status completed
```

### Автоматизировать проверку

Создать скрипт `morning_check.sh`:

```bash
#!/bin/bash
echo "===== УТРЕННЯЯ ПРОВЕРКА ====="
echo ""
echo "📋 ЗАДАЧИ НА СЕГОДНЯ:"
card-cli list --type task --status active --priority high
echo ""
echo "💊 ЛЕКАРСТВА:"
card-cli search "09:00"
echo ""
echo "📅 ВСТРЕЧИ:"
card-cli list --type meeting --status pending
```

Добавить в cron для запуска в 8:00:
```bash
0 8 * * * /path/to/morning_check.sh
```

## Сценарий 3: Управление лекарствами

**Цель:** Полный цикл работы с лекарствами — от добавления до отслеживания приема.

**Кому:** Люди с хроническими заболеваниями

### Шаг 1: Добавить назначение врача

**Создать контакт врача:**
```bash
card-cli create contact "Кардиолог Иванов И.И." \
  --phone "+7-495-123-45-67" \
  --email "ivanov@clinic.ru" \
  --address "Клиника Здоровье, каб. 205"
```

**Запомнить ID:** Сохраните ID контакта для связи с лекарством.

### Шаг 2: Добавить лекарство

```bash
card-cli create medicine "Эналаприл" \
  --description "От давления, назначен кардиологом" \
  --dosage "10 мг" \
  --schedule "09:00, 21:00" \
  --doctor "Кардиолог Иванов И.И." \
  --tags "давление,ежедневно,важно"
```

**Указать дополнительные детали:**
```bash
# Найти ID лекарства
card-cli list --type medicine

# Добавить заметки
card-cli update MEDICINE_ID \
  --description "Принимать после еды. Не пропускать! Курс 3 месяца."
```

### Шаг 3: Настроить напоминания

**Вариант A: Cron (Linux/Mac)**
```bash
# Редактировать cron
crontab -e

# Добавить напоминания
0 9 * * * notify-send "💊 Эналаприл 10 мг"
0 21 * * * notify-send "💊 Эналаприл 10 мг"
```

**Вариант B: Использовать автоматизацию системы**
```bash
# Запустить автоматизацию (проверка каждый час)
card-automation --interval 60

# Или один раз
card-automation --once
```

### Шаг 4: Отслеживать прием

**Создать чеклист на день:**
```bash
# Утро
echo "☐ 09:00 - Эналаприл 10 мг" >> daily_meds.txt

# Вечер
echo "☐ 21:00 - Эналаприл 10 мг" >> daily_meds.txt
```

**Или использовать теги:**
```bash
# Отметить как принято сегодня
card-cli update MEDICINE_ID --tags "давление,ежедневно,принято-2026-01-24"
```

### Шаг 5: Заказать новую упаковку

**Создать напоминание:**
```bash
card-cli create task "Заказать Эналаприл в аптеке" \
  --description "Осталось на 5 дней, заказать 2 упаковки" \
  --priority high \
  --due-date "2026-01-28" \
  --tags "лекарства,аптека"
```

### Шаг 6: Записать результаты

**Добавить в заметки:**
```bash
card-cli create note "Давление - январь 2026" \
  --description "01.01 - 140/90 утро, 135/85 вечер
02.01 - 138/88 утро, 130/80 вечер
..." \
  --tags "здоровье,давление,дневник"
```

## Сценарий 4: Планирование недели

**Цель:** Организовать все дела на неделю вперед.

**Кому:** Все пользователи

### Понедельник: Планирование

**1. Создать задачи на неделю**

```bash
# Задачи по дням
card-cli create task "ПН: Оплатить ЖКХ" --priority high
card-cli create task "ВТ: Сходить в поликлинику" --priority high
card-cli create task "СР: Навестить дочь" --priority medium
card-cli create task "ЧТ: Стирка" --priority low
card-cli create task "ПТ: Уборка квартиры" --priority medium
card-cli create task "СБ: Поход в магазин" --priority high
card-cli create task "ВС: Отдых, чтение книги" --priority low
```

**2. Добавить встречи**

```bash
card-cli create meeting "Прием у терапевта" \
  --location "Поликлиника №5, каб. 12" \
  --meeting-date "2026-01-28T10:30" \
  --participants "Терапевт Петрова А.В." \
  --tags "здоровье"
```

**3. Списки покупок**

```bash
card-cli create shopping "Продукты на неделю" \
  --items "Молоко, Хлеб, Яйца, Курица, Овощи, Фрукты" \
  --budget "3000 руб" \
  --store "Пятёрочка" \
  --tags "еженедельно"
```

### Ежедневная проверка

**Утро каждого дня:**
```bash
# Что нужно сделать сегодня
card-cli list --status active

# С фильтром по тегам (например, "сегодня")
card-cli list --tags "сегодня"
```

**Вечер:**
```bash
# Отметить выполненное
card-cli update TASK_ID --status completed

# Перенести на завтра
card-cli update TASK_ID --tags "завтра"
```

### Воскресенье: Ретроспектива

**Посмотреть выполненные задачи:**
```bash
card-cli list --status completed
```

**Экспортировать для анализа:**
```bash
card-cli export --format json --output week_review.json
```

## Сценарий 5: Семейная забота

**Цель:** Настроить систему для помощи пожилым родителям.

**Кому:** Дети, заботящиеся о родителях

### Настройка для родителей

**1. Установить на компьютер родителей**

Следовать [Сценарию 1](#сценарий-1-первый-запуск)

**2. Создать простые карточки**

```bash
# Лекарства с четким расписанием
card-cli create medicine "Утренняя таблетка" \
  --dosage "1 шт" \
  --schedule "09:00" \
  --description "БОЛЬШИМИ БУКВАМИ: ПРИНЯТЬ ПОСЛЕ ЗАВТРАКА"

# Контакты с крупными деталями
card-cli create contact "ДОЧЬ МАРИЯ (звонить в любое время)" \
  --phone "+7-812-XXX-XX-XX (сохранено в телефоне как МАРИЯ)" \
  --description "Моя дочь, живет в Питере"

# Заметки с важной информацией
card-cli create note "КАК ПОЗВОНИТЬ ДОЧЕРИ" \
  --description "1. Взять телефон
2. Нажать на контакт МАРИЯ
3. Нажать зелёную трубку
4. Подождать ответа"
```

**3. Настроить автоматические напоминания**

Создать файл `reminders.sh`:
```bash
#!/bin/bash
# Напоминания в течение дня

# 9:00 - Утренние лекарства
notify-send "💊 Время принять утреннюю таблетку!" \
  "Не забудьте позавтракать сначала"

# 13:00 - Обед
notify-send "🍽️ Время обеда" \
  "Пора пообедать"

# 21:00 - Вечерние лекарства
notify-send "💊 Время принять вечернюю таблетку!"
```

Добавить в cron.

### Удаленный мониторинг

**Вариант A: Синхронизация через Dropbox**

```bash
# На компьютере родителей
ln -s ~/.card_system/cards ~/Dropbox/parents_cards

# На вашем компьютере
# Вы увидите все их карточки
```

**Вариант B: Еженедельный backup**

```bash
# Настроить автоматический backup
crontab -e

# Каждое воскресенье в 20:00
0 20 * * 0 python3 /path/to/backup_restore.py backup --output ~/Dropbox/parents_backup.zip
```

### Еженедельная проверка

**Вы можете:**
1. Проверить, что родители создают карточки
2. Добавить напоминания о важных встречах
3. Обновить списки лекарств после визита к врачу

```bash
# Добавить напоминание удаленно
# (если настроена синхронизация)
card-cli create task "Позвонить дочери в воскресенье" \
  --priority high \
  --tags "семья,важно"
```

## Сценарий 6: Миграция данных

**Цель:** Перенести все данные на новый компьютер.

**Кому:** При замене оборудования

### Вариант A: Резервное копирование

**На старом компьютере:**

```bash
# 1. Создать резервную копию
cd /path/to/info1/08-Программная-реализация/card_system
python3 backup_restore.py backup --output ~/Desktop/my_cards_backup.zip

# 2. Скопировать файл на USB или отправить по email
```

**На новом компьютере:**

```bash
# 1. Установить систему (Сценарий 1, Шаг 1)

# 2. Восстановить данные
python3 backup_restore.py restore ~/Desktop/my_cards_backup.zip

# 3. Проверить
card-cli list
```

### Вариант B: Копирование директории

**На старом компьютере:**

```bash
# Найти директорию с данными
echo $HOME/.card_system/cards

# Скопировать на USB
cp -r ~/.card_system/cards /Volumes/USB/my_cards
```

**На новом компьютере:**

```bash
# Создать директорию
mkdir -p ~/.card_system

# Скопировать данные
cp -r /Volumes/USB/my_cards ~/.card_system/cards

# Проверить
card-cli list
```

### Вариант C: Облачная синхронизация

**Настроить один раз:**

```bash
# Переместить данные в Dropbox
mv ~/.card_system/cards ~/Dropbox/card_system_data

# Создать символическую ссылку
ln -s ~/Dropbox/card_system_data ~/.card_system/cards
```

**На любом компьютере:**
1. Установить Dropbox
2. Дождаться синхронизации
3. Создать ссылку: `ln -s ~/Dropbox/card_system_data ~/.card_system/cards`

**✅ Готово!** Данные синхронизируются автоматически.

## 💡 Советы и хитрости

### Массовые операции

**Создать несколько карточек из файла:**

```bash
# Создать файл tasks.txt
cat > tasks.txt <<EOF
Купить молоко
Оплатить интернет
Позвонить в поликлинику
Сходить в магазин
EOF

# Создать все задачи
while read task; do
  card-cli create task "$task"
done < tasks.txt
```

### Теги для организации

**Использовать теги для группировки:**

```bash
# По важности
--tags "важно"
--tags "можно отложить"

# По времени
--tags "утро"
--tags "вечер"

# По дням недели
--tags "понедельник"
--tags "суббота"

# По контексту
--tags "дома"
--tags "в поликлинике"
--tags "в магазине"
```

### Шаблоны для повторяющихся задач

**Создать скрипт для еженедельных задач:**

```bash
#!/bin/bash
# weekly_tasks.sh

# Каждый понедельник
card-cli create task "Оплатить ЖКХ" --tags "финансы,еженедельно"

# Каждую субботу
card-cli create task "Большая уборка" --tags "дом,еженедельно"

# Каждое воскресенье
card-cli create task "Приготовить на неделю" --tags "еда,еженедельно"
```

Запускать каждое воскресенье вечером.
